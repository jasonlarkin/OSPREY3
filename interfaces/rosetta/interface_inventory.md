# Rosetta: interface inventory 

## Object graph (core)

- **Pose**
  - primary state container (structure + annotations).
- **Pose::Conformation + Pose::Energies**
  - Pose explicitly separates kinematics/structure (Conformation) from cached score data (Energies).
- **Mover**
  - operator applied to a Pose (mutation/proposal/relax/packing step).
  - protocols are typically composed as sequences/graphs of Movers.
- **ScoreFunction**
  - objective function; weighted composition of score terms.
- **EnergyMethod (score term)**
  - a pluggable term contributing to the ScoreFunction.
  - many variants: pairwise-like terms, environment terms, solvation, constraints, etc.

## Structural pattern (high value)

- **Operator pipeline**: a protocol is an explicit chain of state transforms (Movers).
- **Objective composition**: ScoreFunction is a configurable weighted sum over EnergyMethods.
- **Extensibility**:
  - add new Movers (new operators / search steps)
  - add new EnergyMethods (new scoring terms)

This is the closest **general conformation search interface** exemplar among the cloned set.
